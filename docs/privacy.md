# Privacy & Ethics
- Educational only; NOT medical advice. Emergency banner on every screen.
- No real patient data (PII) allowed. All cases are synthetic/anonymized teaching vignettes.
- Local-first: accounts + SRS stored in browser + SQLite; cloud sync is explicit export/import JSON only.
- Client errors log technical messages only (no health data).
- Media: `assets/medimg/*.svg` are original diagrams (CC0). Textbook figures are NOT copied; chapter maps link to print/e-book page refs. External PDFs link to publishers.
